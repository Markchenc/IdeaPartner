# Original idea reconstruction in stage 3

Keep all six sections: problem_definition, limitations_and_core_difficulty, contribution_design, method_construction, experimental_setting, expected_difficulties.

Organize the original proposal, not a revised proposal that would be easier to defend. Distinguish researcher_stated, evidence_supported, inferred and missing items. User statements carry original-input line ranges; evidence-supported context carries evidence references. Do not present a review recommendation as a researcher-authored method.

Each section has at least one item; explicitly missing content is valid and must not be filled with invented detail. Inferences are labelled. Check whether stage 2 evaluated the same claims as the original idea; resolve important scope mistakes through a targeted recheck or a qualified final conclusion.

Six sections form a final deliverable inside s3, not a separate agent or pre-review gate.
